## Dicta Speech-to-Text

Turn your voice into text instantly. Dicta is a lightweight, browser-based speech-to-text demo built on the Web Speech API with a clean, responsive UI.

### What You Can Do

- Speak continuously and see live transcription
- Start/stop listening with one click
- Clear the transcript with a single action

### How to Use

1. Open index.html in a modern browser (Chrome or Edge recommended).
2. Click the microphone area.
3. Allow microphone access when prompted.
4. Start speaking. Click again to stop.

### Controls

- Microphone button: Start/stop listening
- Clear button: Reset the transcript

### Tech Stack

- HTML
- CSS
- JavaScript (Web Speech API)

### Project Structure

- index.html
- style/style.css
- script/script.js
- resources/img/

### Browser Support

The Web Speech API is not supported in all browsers. If recognition does not start, try Chrome or Edge.

### Troubleshooting

- No prompt for microphone? Check browser permissions for the file or site.
- No transcription? Ensure the browser supports Web Speech API and try again.
- Silence breaks the text? Keep speaking or click to restart listening.
